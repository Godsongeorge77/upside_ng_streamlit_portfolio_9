# Upside ng — Streamlit Portfolio

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud
1. Extract the ZIP archive so `app.py` and `requirements.txt` are in your project folder/repository root.
2. Deploy on [share.streamlit.io](https://share.streamlit.io) with `app.py` as the main file path.
